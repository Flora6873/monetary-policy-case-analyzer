## 一、货币与货币制度

### 货币的本质与职能
- **货币（Money）**：固定充当一般等价物的特殊商品。本质是**价值尺度与流通手段的统一**。
- 五大职能：价值尺度、流通手段、贮藏手段、支付手段、世界货币。
  - 前两者为**基本职能**，后三者为派生职能。
- 易错点：价值尺度是观念上的货币；流通手段必须是现实的货币（但可用符号代替）。

### 货币形式的演变
实物货币 → 金属货币 → 代用货币（可兑换纸币）→ 信用货币（不可兑换）→ 电子货币/数字货币。

### 货币制度
| 类型 | 核心特征 |
|---|---|
| 银本位制 | 白银为本位币 |
| 金银复本位制 | 平行本位 / 双本位 / 跛行本位；**格雷欣法则**（劣币驱逐良币） |
| 金本位制 | 金币本位（典型）→ 金块本位 → 金汇兑本位 |
| 不兑现信用货币制度 | 现代主流；央行垄断发行，与贵金属脱钩 |

**格雷欣法则**：在双本位制下，当法定比价与实际市场比价偏离时，实际价值高的"良币"被熔化或输出，"劣币"充斥流通。

### 货币层次划分（中国口径）
- M0 = 流通中现金
- M1 = M0 + 单位活期存款
- M2 = M1 + 单位定期存款 + 储蓄存款 + 其他存款
- M1 反映**现实购买力**，M2 反映**潜在购买力**。

## 二、信用与利率

### 信用形式
商业信用（基础）、银行信用（主导）、国家信用、消费信用、国际信用。

### 利息与利率
- **利率（Interest Rate）**：借贷期内利息与本金的比率，是资金的价格。
- 名义利率 vs 实际利率（费雪方程：$1+i=(1+r)(1+\pi)$）。
- 单利 vs 复利；固定利率 vs 浮动利率；官定利率 vs 市场利率。

### 利率决定理论（重点）
| 理论 | 核心主张 | 关键变量 |
|---|---|---|
| 古典利率理论 | 实物因素决定，储蓄=投资 | 储蓄、投资 |
| 凯恩斯流动性偏好 | 货币因素决定，货币供求 | 交易/预防/投机动机 |
| 可贷资金理论 | 综合实物与货币因素 | 可贷资金供求 |
| IS-LM | 收入与利率同时决定 | 产品市场+货币市场均衡 |

**流动性陷阱**：利率极低时，货币需求弹性无穷大，增发货币不再降低利率，货币政策失效。

### 利率期限结构
- 预期理论：长期利率 = 未来短期利率的预期平均。
- 市场分割理论：各期限市场相互独立。
- 流动性偏好理论：长期利率含期限溢价。

## 三、金融机构体系

### 商业银行
- 三大业务：负债业务、资产业务、中间业务。
- **信用创造**功能：通过贷款派生存款，扩大货币供应量。
- 经营管理理论演变：资产管理 → 负债管理 → 资产负债综合管理 → 全面风险管理。
- **巴塞尔协议**：核心资本充足率、杠杆率、流动性覆盖率（LCR）、净稳定资金比例（NSFR）。

### 中央银行
- 性质："发行的银行""银行的银行""政府的银行"。
- 三大职能：制定执行货币政策、维护金融稳定、提供金融服务。
- 资产负债表：资产端（外汇、对政府债权、对存款机构债权）↔ 负债端（流通中现金、准备金存款）。

### 非银行金融机构
证券公司、保险公司、信托、基金、政策性银行等。

## 四、金融市场

- 货币市场（短期）：同业拆借、回购、票据、大额存单、国库券。
- 资本市场（长期）：股票、债券。
- 金融衍生工具：远期、期货、期权、互换。
- 有效市场假说（EMH）：弱式、半强式、强式。

## 五、货币需求与货币供给

### 货币需求理论
| 理论 | 公式/要点 |
|---|---|
| 现金交易说（费雪） | $MV=PT$ |
| 现金余额说（剑桥） | $M=kPY$ |
| 凯恩斯货币需求 | $M=L_1(Y)+L_2(r)$ |
| 弗里德曼现代货币数量论 | 货币需求是资产组合选择的结果，函数稳定 |

### 货币供给
- **基础货币 B（高能货币）** = 流通中现金 + 准备金存款。
- **货币乘数 m** = 货币供应量 / 基础货币。
- 货币供应量 $M_s = m \times B$。
- 影响货币乘数的因素：法定准备金率、超额准备金率、现金漏损率、定期存款比率。

## 六、通货膨胀与通货紧缩

### 通货膨胀
- 类型：需求拉动型、成本推动型、结构型。
- 效应：强制储蓄效应、收入分配效应（利于债务人、不利于债权人）、财富分配效应。
- 治理：紧缩货币政策、收入政策、供给政策。

### 通货紧缩
物价持续下降；伴生经济衰退，形成"债务-通缩螺旋"。

### 菲利普斯曲线
短期：通胀率与失业率负相关；长期：垂直线（自然失业率假设）。

## 七、货币政策

### 最终目标
物价稳定、充分就业、经济增长、国际收支平衡、金融稳定。（多目标冲突）

### 中间目标
- 中介指标：货币供应量、利率、汇率。
- 操作指标：存款准备金、基础货币。（相关性、可测性、可控性、抗干扰性）

### 政策工具
| 类型 | 工具 | 特点 |
|---|---|---|
| 一般性 | 法定准备金率 | 作用猛烈，不常动用 |
| 一般性 | 再贴现率 | 告示效应，被动 |
| 一般性 | 公开市场业务 | 最灵活、最常用 |
| 选择性 | 消费信用控制、证券市场信用控制等 | 定向调节 |
| 补充性 | 道义劝告、窗口指导 | 非强制 |
| 创新性 | MLF、SLF、PSL、LPR | 中国央行常用 |

### 传导机制
政策工具 → 操作指标 → 中介指标 → 最终目标。
主要渠道：利率渠道、信贷渠道、资产价格渠道、汇率渠道。

## 八、金融风险与监管

- 金融风险类型：信用、市场、操作、流动性、系统性风险。
- 金融监管目标：维护安全、保护消费者、提高效率。
- 分业监管 vs 功能监管 vs 宏观审慎管理。
- 存款保险制度；最后贷款人职能。

## 逻辑主线速记

> 货币起源 → 货币制度确立 → 信用扩张产生利率 → 金融机构（银行）创造存款 → 中央银行调控基础货币 → 通过货币乘数放大为货币供应量 → 影响物价与产出 → 需要货币政策与金融监管保驾护航。

这条主线把全课程串成一个闭环，复习时用它检验知识点是否"挂得上钩"。
