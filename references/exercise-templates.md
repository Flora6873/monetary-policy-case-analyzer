# 习题模板库

生成练习题时套用以下模板，确保题干严谨、解析完整。

---

## 题型一：单项选择题

```markdown
**Q1.** 下列关于基础货币的表述，正确的是（　　）

A. 基础货币等于流通中现金
B. 基础货币是中央银行能够直接控制的货币
C. 基础货币的增减不取决于中央银行
D. 基础货币又称狭义货币供应量

<details>
<summary>答案与解析</summary>

**答案：B**

**解析：** 基础货币 $B$ = 流通中现金 + 准备金存款，故 A 错；基础货币由央行通过资产业务投放，央行可直接控制，B 正确、C 错；狭义货币供应量 M1 = M0 + 单位活期存款，与基础货币不是同一概念，D 错。

**易错点：** 混淆"基础货币"与"M1"。记住：基础货币是**央行的负债**，而 M1/M2 是**货币供应量**，后者 = 基础货币 × 货币乘数。

</details>
```

要点：
- 四个选项尽量覆盖一个知识点的不同侧面，错误选项要有"迷惑性"但明确可判错。
- 解析必须指出每个错误选项错在哪里。

## 题型二：多项选择题

```markdown
**Q2.** 下列属于中央银行"银行的银行"这一职能表现的有（　　）

A. 集中存款准备金
B. 充当最后贷款人
C. 组织全国清算
D. 代理国库

<details>
<summary>答案与解析</summary>

**答案：ABC**

**解析：** "银行的银行"体现为：集中准备金（A）、最后贷款人（B）、组织清算（C）。代理国库属于"政府的银行"职能（D 错）。

**易错点：** 央行三大职能（发行的银行/银行的银行/政府的银行）常被交叉设问，需按职能归类记忆。

</details>
```

## 题型三：名词解释

```markdown
**Q3.** 名词解释：**流动性陷阱**

<details>
<summary>参考答案</summary>

**参考答案：**

流动性陷阱是指当利率降低到某一极低水平时，人们预期利率将不再下降（债券价格不再上升），因而愿意持有任意数量的货币，货币需求的利率弹性趋于无穷大。

此时，中央银行无论增加多少货币供应量，都会被公众以货币形式持有，利率不再下降，从而货币政策失效，只能依靠财政政策刺激经济。

**评分要点：** ① 概念定义 ② 提出者（凯恩斯） ③ 货币政策失效的结论 ④ 利率弹性无穷大这一机制。

</details>
```

要点：名词解释强调**定义 + 机制 + 意义**三段式，缺一不可。

## 题型四：简答题

```markdown
**Q4.** 简述中央银行公开市场业务作为货币政策工具的优点。

<details>
<summary>参考答案</summary>

**参考答案：**

公开市场业务是央行在金融市场上买卖有价证券以调节货币供应量的活动，其优点包括：

1. **主动权在央行**：可主动出击，不像再贴现率那样被动等待商业银行行为。
2. **灵活可调**：可大可小、可正可反，便于微调。
3. **可逆性强**：买入与卖出可对冲，便于纠错。
4. **精确可控**：交易量直接对应准备金的变动。
5. **告示效应弱**：不似法定准备金率那样引发强烈市场震动。

**评分要点：** 5 点答出 4 点即可得满分，需结合实际展开而非罗列名词。

</details>
```

## 题型五：计算题

```markdown
**Q5.** 某国基础货币为 1000 亿元，法定准备金率 10%，超额准备金率 2%，现金漏损率 5%，定期存款与活期存款之比为 0.3，定期存款准备金率 5%。求：

（1）货币乘数；
（2）货币供应量 M2。

<details>
<summary>答案与解析</summary>

**答案：**

（1）**已知条件：** $B=1000$ 亿，$rr=0.10$，$e=0.02$，$c=0.05$，$t=0.3$，$rr_t=0.05$

**选用公式：** $m = \dfrac{1+c+t}{c+rr+e+t \cdot rr_t}$（M2 口径货币乘数公式）

**代入计算：**
$$m = \frac{1+0.05+0.3}{0.05+0.10+0.02+0.3 \times 0.05} = \frac{1.35}{0.185} \approx 7.297$$

（2）$M_2 = m \times B = 7.297 \times 1000 \approx 7297$（亿元）

**结论含义：** 基础货币每增加 1 元，货币供应量 M2 增加约 7.3 元，体现了银行体系的信用派生能力。

**易错点：** ① 忘记把百分数转为小数；② M2 口径漏掉 $t$ 项；③ 分子只写 1 而漏掉 $c+t$。

</details>
```

计算题解析**必须包含五个环节**：已知条件 → 选用公式（含适用条件）→ 代入计算 → 结论含义 → 易错点。

## 题型六：论述题 / 材料分析题

```markdown
**Q6.** 结合我国实际情况，论述数量型货币政策工具向价格型工具转型的必要性。

<details>
<summary>参考要点</summary>

**参考要点（评分框架）：**

**一、背景**（2 分）——利率市场化推进、货币政策框架转型要求。

**二、数量型工具的局限**（4 分）
- 货币乘数不稳定，M2 目标可控性与相关性下降；
- 金融创新与影子银行削弱数量指标代表性；
- 数量调控易造成信贷资源错配。

**三、价格型工具的优势**（4 分）
- 以利率为核心，传导更市场化；
- 通过 LPR 改革疏通利率传导；
- 更适应直接融资比重上升的经济结构。

**四、结论与建议**（2 分）——完善利率走廊、培育基准利率、提升央行政策利率权威性。

**评分要点：** 论点清晰、论据充分、层次分明、联系现实。
</details>
```

论述题强调**总-分-总结构**与**现实结合**，禁止空喊口号。
