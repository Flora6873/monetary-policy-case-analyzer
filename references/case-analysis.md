# 案例剖析方法论与案例库

本文件是案例剖析器的方法论核心。剖析任何案例时，先在这里找**同类案例的模板**，再套用 SKILL.md 的五步法。

---

## 一、剖析框架详解

### 框架图

```
【事实层】  事件还原：何时、何主体、何动作、何数字、何背景
              ↓
【理论层】  理论定位：挂到哪一章、哪个理论、哪个概念（含双教材差异）
              ↓
【机制层】  传导链条：政策动作 → 操作指标 → 中介指标 → 最终目标
              ↓
【效应层】  影响推演：对银行/企业/居民/金融市场分别意味着什么
              ↓
【评价层】  批判性评价：预期 vs 现实、约束条件、争议、替代方案
```

**三层递进原则**：事实层只陈述不下判断；机制层只讲因果不下结论；效应层才谈影响。层次混乱是低质量分析的通病。

## 二、五类高频案例的剖析模板

### 类型 A：数量型货币政策工具（降准 / 公开市场操作）

**识别特征**：央行调整存款准备金率、开展逆回购、MLF 操作。

**剖析重点**：
- 工具归属：一般性工具（准备金率）还是创新工具（MLF/SLF/PSL）
- 传导：基础货币变化 → 货币乘数放大 → 货币供应量变化
- **必算**：准备金变动带来的货币供应量放大效应

```bash
python3 scripts/calc.py money_multiplier --rr 0.105 --c 0.05 --e 0.02
python3 scripts/calc.py deposit_expansion --reserve 0.105 --base 1000
```

**评价抓手**：数量型工具的"可控性"与"副作用"（作用猛烈、信号效应强）。

---

### 类型 B：价格型货币政策工具（降息 / LPR 调整 / 利率走廊）

**识别特征**：MLF 利率、LPR、逆回购利率、存款利率调整。

**剖析重点**：
- 与利率决定理论挂钩（流动性偏好、可贷资金理论）
- 传导：政策利率 → 市场利率 → 存贷款利率 → 融资成本 → 投资消费
- **必算**：实际利率（费雪方程），研判真实融资成本变化

```bash
python3 scripts/calc.py fisher --nominal 0.035 --inflation 0.02
```

**评价抓手**：利率传导是否畅通（LPR 改革的核心目的）、利率有效下限、流动性陷阱风险。

---

### 类型 C：汇率与国际收支类（美联储加息 / 人民币汇率变动）

**识别特征**：主要经济体货币政策、汇率波动、资本流动。

**剖析重点**：
- 利率平价理论、购买力平价的现实偏离
- 传导：中美利差 → 资本流动 → 汇率 → 进出口 → 国内货币政策空间
- **必算**：掉期率、利差

```bash
python3 scripts/calc.py exchange_swap --buy 7.10 --sell 7.15 --amount 1000000
```

**评价抓手**：蒙代尔"不可能三角"——汇率稳定、资本自由流动、货币政策独立性的取舍。

---

### 类型 D：金融风险与监管类（银行风险事件 / 监管新规）

**识别特征**：金融机构风险处置、资本充足率新规、存款保险。

**剖析重点**：
- 风险类型界定（信用/市场/操作/流动性/系统性）
- 传导：单机构风险 → 同业传染 → 系统性风险
- 巴塞尔协议相关指标的影响

**评价抓手**：监管的成本与收益权衡、宏观审慎 vs 微观审慎。

---

### 类型 E：货币现象类（通胀数据 / M2 变动 / 数字货币）

**识别特征**：CPI/PPI 数据、货币供应量数据、数字人民币进展。

**剖析重点**：
- 货币需求理论对应（交易方程、剑桥方程、凯恩斯、弗里德曼）
- 传导：货币量 → 价格水平 → 通胀预期
- **必算**：通胀率、M2 与 GDP 关系

**评价抓手**：货币"数量说"在当代的有效性争议、金融创新对货币指标的冲击。

## 四、中国货币政策工具速查（剖析时定位用）

| 工具 | 类型 | 特征 |
|---|---|---|
| 法定准备金率 | 一般性 | 作用猛烈，不轻用，强信号 |
| 公开市场操作（逆回购/正回购） | 一般性 | 最常用，灵活，调节短期流动性 |
| MLF（中期借贷便利） | 创新性 | 提供中期基础货币，引导 LPR |
| SLF（常备借贷便利） | 创新性 | 利率走廊上限 |
| PSL（抵押补充贷款） | 创新性 | 定向支持棚改、基建 |
| 再贷款/再贴现 | 一般性 | 定向、结构性 |
| 结构性货币政策工具 | 创新性 | 精准滴灌特定领域 |

**利率传导链（中国当前）**：
```
政策利率（逆回购/MLF） → LPR → 企业贷款利率 / 房贷利率
```

## 五、剖析质量自检清单

- [ ] 事件还原阶段有无掺入主观分析？
- [ ] 关键数字是否都有出处，没有臆造？
- [ ] 理论定位是否精确到具体理论，而非泛泛而谈？
- [ ] 传导链条每一环是否都给出因果解释？
- [ ] 数值推演是否经 `scripts/calc.py` 验证？
- [ ] 影响推演是否分主体、有逻辑？
- [ ] 评价部分是否呈现多元观点而非单一结论？
- [ ] 有无"要点回扣"把案例连回考点？

## 六、反面示例（剖析中最常见的四种毛病）

| 毛病 | 表现 | 正确做法 |
|---|---|---|
| **理论堆砌** | 大段复述课本定义，不联系案例 | 定义一两句带过，重点在"这个案例如何体现它" |
| **链条断裂** | 从政策直接跳到结论 | 补齐每一环因果 |
| **数字张口就来** | "大概上升 5%" 无依据 | 调用计算脚本，标注来源 |
| **只有赞美或只有批评** | 一边倒 | 呈现预期效果与偏差，多方观点 |
